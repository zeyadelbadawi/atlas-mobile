**Critic Verification**: Automatically verified (bypassed critic review). (Confidence: High)

### Play Console Requirements

#### All learning features are behind an academy sign-in, so Play reviewers need working demo credentials.
- **Policy**: **Login credentials**
- **Severity**: 🟡 Important
- **Files**: [providers.dart](../lib/app/providers.dart), [auth_repository.dart](../lib/core/auth/auth_repository.dart)
- **Evidence**: AuthRepository.signIn gates the shell; the app opens on the academy picker and sign-in screens (routes /picker, /academy/sign-in).

**Critic Verification**: Every learning route redirects to the academy picker or sign-in when signed out (router redirect); reviewers need credentials. (Confidence: High)
- **Recommendation**: In Play Console > App access, give the demo academy name, a non-expiring learner email and password, and say the account skips the emailed sign-in code (see docs/STORE_REVIEW_NOTES.md).
- **References**:
  - https://support.google.com/googleplay/android-developer/answer/15748846
