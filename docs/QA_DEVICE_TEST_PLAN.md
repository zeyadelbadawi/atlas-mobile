# خطة اختبار تطبيق أطلس على الموبايل (يدوي)

> اتعملت بسكيل qa-test-planner، 31 أكتوبر 2026.
> الاختبارات الأوتوماتيك (282 اختبار) بتغطي الشاشات والمنطق. الخطة دي للي محتاج **موبايل حقيقي ونت حقيقي وحساب حقيقي**.
> علّم كل حالة: ✅ نجحت / ❌ فشلت (واكتب اللي حصل) / ⏭️ اتخطت.

## البيئة

| | |
|---|---|
| أندرويد | APK آخر نسخة، موبايل متوسط (مثلًا 4 جيجا رام) |
| iPhone | IPA من GitHub Actions + Sideloadly (حساب Apple مجاني: من غير Push ولا Sign in with Apple) |
| الأكاديميات | `demoo` (لوجو أصفر)، `ziadd` (من غير لوجو) |
| الحساب | حساب طالب فقط، مش Staff |

**الأولوية:** P0 = لو فشل التطبيق مش صالح للنشر · P1 = لازم يتصلح قبل النشر · P2 = يتصلح في الإصدار الجاي.
